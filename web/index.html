How it works

Up and running in 3 steps

01

Upload

Send your script or .zip project to the bot. Admins get notified instantly.

02

Approval

An admin reviews the file and approves it — you get a notification when it's live.

03

Run & manage

Hit start, watch logs, restart on demand. Your bot stays online 24/7.

For the owner

Full control panel

Approval queue

Inline approve / reject buttons on every uploaded file, plus a live pending counter on the main menu.

Run everything

One command restarts every approved bot after a crash or a server reboot.

Subscriptions

Grant extra file slots with day-based expiry. Free users get 2, premium 15, admins unlimited.

Broadcast

Flood-safe broadcasting to all active users with batch delays and retry handling.
